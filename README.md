# Zad

**Zad — Arabic Learning App**
**Creator and copyright owner: Mohammad Farmani**

Copyright © 2026 Mohammad Farmani. All rights reserved.

Zad (ضاد) is an Arabic learning app for Persian speakers, for Android and iPhone: levels A1 to C1, vocabulary, grammar, practice, tests, the Quran and a library. It works offline.

**Website and downloads: https://mfarmani85.github.io/Zad/**

## Download

Install the official app from [`Zad.apk`](Zad.apk) (version 1.3.1, Android 7.0 or newer). On your phone, allow "Install unknown apps" for your browser or file manager, then open the APK.

For Arabic audio, make sure an Arabic voice is installed in Android's text-to-speech settings (Settings → System → Text-to-speech → Google Speech Services → Install voice data → Arabic).

## iPhone

1. Open **https://mfarmani85.github.io/Zad/** in **Safari** and tap **باز کردن ضاد** (Open the app).
2. Tap the **Share** button, then **Add to Home Screen**, then **Add**.
3. Open Zad from your home screen. After the first launch it works offline.
