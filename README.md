Zad is an Arabic learning app for Android. It uses Android's built-in text-to-speech for Arabic pronunciation.

## Download

Install the official app from [`Zad.apk`](Zad.apk) (version 1.2, Android 7.0 or newer). On your phone, allow "Install unknown apps" for your browser or file manager, then open the APK.

For Arabic audio, make sure an Arabic voice is installed in Android's text-to-speech settings (Settings → System → Text-to-speech → Google Speech Services → Install voice data → Arabic).
